# reyku-site-page

A clean, responsive personal portfolio landing page built to showcase my web development projects, technical skills, and certifications.

![Portfolio Preview](./import/IMG_20260807_200718-removebg-preview.png)

---

##  Live Demo

Check out the live website here: https://rayver-reyku.github.io/reyku-site-page/

---

## Built With

* **HTML5** - Structure and semantic layout
* **CSS3** - Custom styling, flexbox layouts, animations, and responsive design
* **Devicon** - Technology icons

---

## Features

* **Hero Section:** Introduction with custom profile presentation.
* **Tech Stack Carousel:** Dynamic showcase of technologies worked with.
* **Projects Showcase:** Highlighted list of personal and academic projects.
* **Certificates & Contact:** Section for credentials and reaching out.
* **Fully Responsive:** Styled to adapt across mobile, tablet, and desktop viewports.
